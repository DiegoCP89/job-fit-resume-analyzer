# Job Fit Resume Analyzer

A Python web application that analyzes the compatibility between a resume and a job description.

The user uploads a resume in PDF format and pastes a job description. The system extracts the resume text, compares it with the job requirements, calculates a compatibility score, and displays matched and missing skills.

## Features

* PDF resume upload
* Job description input
* Text extraction from PDF
* Keyword-based resume analysis
* Compatibility score
* Matched skills
* Missing skills
* Improvement suggestions

## Tech Stack

* Python
* Flask
* HTML
* CSS
* PyMuPDF
